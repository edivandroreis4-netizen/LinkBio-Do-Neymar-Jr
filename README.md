## 🎯 Conceitos aplicados

### 🔹 Pseudo-classes

Utilizadas para trabalhar estados dos elementos:

* `:hover` → interação ao passar o mouse
* `:active` → ao clicar
* `:first-child` → primeiro elemento

```css
a:hover {
  transform: scale(1.05);
}
```

---

### 🔹 Pseudo-elementos

Utilizados para estilização de partes específicas:

* `::before` → conteúdo antes
* `::after` → conteúdo depois
* `::first-letter` → primeira letra

```css
p::before {
  content: "🔥 ";
}
```
